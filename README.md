# CV Application
A web-based resume builder where the user fills out forms with their information and their CV is updated in real time.

Netlify deployment [Here](https://devchap8-cv-application.netlify.app/) 

## Tech Stack
* React
* Vanilla CSS
* HTML

## What I learned
* Constructing React components
* Managing state between multiple elements
* Using Hooks
* Lifting state to parent elements
* Responsive design
